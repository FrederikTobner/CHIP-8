keyBoardState_t keyboard_scancode_to_key_code ( SDL_Scancode scancode)
static

Converts a key of the keyboard to the key code of the CHIP-8 keyboard.

The keys 0-9 (number row and numpad) and A-F are mapped to the corresponding CHIP-8 key

Parameters
scancodeThe scancode of the key on the keyboard
Returns
The key code of the CHIP-8 key, 0 if the key is not mapped
